# Start

Persoonlijke planner als Android-app (Capacitor).

- `www/index.html`: de hele app (webcode)
- `android/`: het Android-project (widget, snelkoppelingen, agenda, herinneringen)
- `.github/workflows/apk.yml`: bouwt bij elke wijziging een APK en zet die onder Releases

Downloaden: ga naar Releases en pak `Start.apk` van de nieuwste release.
